# Stratégie de publication — jusqu'au trail

## Deux formats par jour
| | Vidéo **Défi** | Vidéo **Communauté** |
|---|---|---|
| Rôle | Fidéliser : on suit ton histoire | Attirer : utile pour un inconnu |
| Sujet | Ta séance du jour, tes sensations, ton avancée | Conseil, erreur, classement, test, avis tranché |
| Texte | « Jour X/22 » + prépa 1er trail | Pas de « Jour X/22 » |
| Durée | 25–45 s | 40–80 s |
| Hook | Enjeu / suspense / résultat d'abord | Question / erreur / liste / avis tranché (voir `HOOKS.md`) |
| Fin | « Abonne-toi pour la suite » | Question pour faire commenter + « Abonne-toi pour la suite » |

## Règles
- **Relier les deux** : la vidéo Communauté mentionne le défi (« je prépare mon premier trail ») ; la vidéo Défi peut annoncer le sujet Communauté.
- **Espacer** les publications (ex. Défi le matin / midi, Communauté le soir).
- **Tourner léger** : la vidéo Défi peut être faite pendant la séance ; la vidéo Communauté peut être tournée à l'avance (plusieurs d'un coup).
- **Bilan au bout de 7 jours** : comparer vues, durée moyenne, % regardé en entier, abonnés gagnés par format → garder ce qui marche, ajuster le reste.
- Si c'est trop lourd : 1 Défi par jour + 1 Communauté **tous les 2 jours**.
