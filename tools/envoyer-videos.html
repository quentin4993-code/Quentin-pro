Sur la page GitHub

  1. Si la page est mal affichée : « aA » → Demander le site pour ordinateur.
  2. Descends jusqu'à « Attach binaries… » et choisis tes vidéos.
  3. Attends que chaque fichier ait fini de charger.
  4. Touche le bouton vert Publish release.
  5. Dis à Claude : « c'est publié, jour X, Y km ».

Le dépôt est public : les vidéos envoyées sont visibles par tout le monde. Pense à supprimer l'envoi une fois la vidéo montée.
